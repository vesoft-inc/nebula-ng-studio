# Studio Server

`apps/server` owns the Go HTTP service, Graphd connections, authentication, and Studio metadata persistence. Frontend HTTP translation and layout/settings protocols belong to [Studio Server adapters](STUDIO-SERVER-ADAPTERS.md).

- **Session lifetime:** Graphd clients and OAuth2 token sessions live in process memory. Fixed signing/encryption secrets do not restore them after restart; users must sign in again. Missing clients return `ErrNoClient`; missing OAuth2 sessions return `ErrSession`. See [authentication](../../apps/server/pkg/auth/authorize.go).
- **Query isolation:** `/nebula/console/execGql` retains a connection per login client so subsequent queries can access session state such as warnings. `/gql/exec` borrows and releases a pooled connection. Keep metadata queries separate from the Console connection; even PING clears `SHOW WARNINGS` results. See [query execution](../../apps/server/internal/service/gateway.go) and [Console connections](../../apps/server/pkg/nebula/console.go).
- **Response compatibility:** Business endpoints use `ServiceContext.ResponseHandler`; preserve both HTTP status and business `code/message`, including `ErrNotFound`, `ErrSession`, and `ErrNoClient`. Health endpoints deliberately return their own small JSON bodies. See [response handling](../../apps/server/internal/svc/servicecontext.go) and [probes](../../apps/server/internal/handler/health/response.go).
- **Metadata readiness:** SQLite/MySQL stores Studio snapshots, sketches, icons, and global configuration. Migration application is controlled by `Database.AutoMigrate`; readiness checks the database and migration ledger without applying changes. Neither health endpoint checks Graphd. See [database initialization](../../apps/server/internal/model/db.go) and [migration checks](../../apps/server/internal/model/migration.go).

API generation and Go validation follow [CONTRIBUTING](../../CONTRIBUTING.md); frontend build side effects are documented in [VERIFICATION](VERIFICATION.md). Configuration and delivery instructions remain in [deploy](../../deploy).
