# LESSONS

| ID  | Trigger and correction                                                                                                                                                                                                  | Evidence                                                                                                                                                   |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| L02 | Source aliases can hide artifact dependency leaks. Hiding JS exports or using import type does not isolate declarations; inspect the complete dependency graph of the current dist.                                     | [Boundary checker](../../packages/studio-ui/scripts/check-boundaries.mjs)                                                                                  |
| L03 | An active flag reset to true can admit old operations. Use operation generations and cancellation signals; distinguish page callbacks from scope synchronization, including StrictMode and service replacement.         | [Provider](../../packages/studio-ui/src/provider.test.tsx), [Panel](../../packages/studio-ui/src/schema-tree-panel.test.tsx)                               |
| L04 | Refresh failure must not turn a successful creation into a failed write or navigate after unmount. Handle the write, refresh, and completion callback separately.                                                       | [Tree bindings](../../packages/studio-ui-internal/src/schema/useSchemaTreeBindings.test.tsx)                                                               |
| L05 | Splitting tree keys corrupts business names containing hyphens. Read rawData or semantic selections; let the Router decode URL parameters once.                                                                         | [Panel](../../packages/studio-ui/src/schema-tree-panel.test.tsx), [Web paths](../../apps/web/src/app/paths.test.ts)                                        |
| L06 | Snapshot parameter changes may reuse callbacks bound to an old workspace. Remount the shared canvas subtree by snapshotId; retain the overlay's positioning container when splitting layouts.                           | [Canvas interaction](../../packages/studio-ui-internal/src/explorer/Graph/index.test.tsx)                                                                  |
| L07 | Creating editor services on every page mount creates independent write queues. Cache services by identity within the session; capture identity/key/data at enqueue time and stop invalidated work.                      | [Web service sessions](../../apps/web/src/services/studioServer.test.ts)                                                                                   |
| L09 | Axios may reject a 404 carrying a valid business error. Normalize only valid business bodies; preserve large integers and reject network failures, cancellation, and malformed JSON instead of returning empty success. | [Adapter contract and example](STUDIO-SERVER-ADAPTERS.md), [Configuration regressions](../../packages/studio-ui/src/adapters/studio-server/config.test.ts) |
