# LESSONS

| ID  | Trigger and correction                                                                                                                                                                                                  | Evidence                                                                                                                                                   |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| L02 | Source aliases can hide artifact dependency leaks. Hiding JS exports or using import type does not isolate declarations; inspect the complete dependency graph of the current dist.                                     | [Boundary checker](../../packages/studio-ui/scripts/check-boundaries.mjs)                                                                                  |
| L03 | An active flag reset to true can admit old operations. Use operation generations and cancellation signals; distinguish page callbacks from scope synchronization, including StrictMode and service replacement.         | [Provider](../../packages/studio-ui/src/provider.test.tsx), [Panel](../../packages/studio-ui/src/schema-tree-panel.test.tsx)                               |
| L04 | Refresh failure must not turn a successful creation into a failed write or navigate after unmount. Handle the write, refresh, and completion callback separately.                                                       | [Tree bindings](../../packages/studio-ui-internal/src/schema/useSchemaTreeBindings.test.tsx)                                                               |
| L05 | Splitting tree keys corrupts business names containing hyphens. Read rawData or semantic selections; let the Router decode URL parameters once.                                                                         | [Panel](../../packages/studio-ui/src/schema-tree-panel.test.tsx), [Web paths](../../apps/web/src/app/paths.test.ts)                                        |
| L06 | Snapshot parameter changes may reuse callbacks bound to an old workspace. Remount the shared canvas subtree by snapshotId; retain the overlay's positioning container when splitting layouts.                           | [Canvas interaction](../../packages/studio-ui-internal/src/explorer/Graph/index.test.tsx)                                                                  |
| L07 | Creating editor services on every page mount creates independent write queues. Cache services by identity within the session; capture identity/key/data at enqueue time and stop invalidated work.                      | [Web service sessions](../../apps/web/src/services/studioServer.test.ts)                                                                                   |
| L09 | Axios may reject a 404 carrying a valid business error. Normalize only valid business bodies; preserve large integers and reject network failures, cancellation, and malformed JSON instead of returning empty success. | [Adapter contract and example](STUDIO-SERVER-ADAPTERS.md), [Configuration regressions](../../packages/studio-ui/src/adapters/studio-server/config.test.ts) |
| L10 | A mounted editor can outlive its Controller. Bind the handle in an effect keyed by the editor and owner callback, and release it through the callback captured by that effect.                                          | [Editor handoff](../../packages/studio-ui-internal/src/editor/GqlEditor/Editor.test.tsx)                                                                   |
| L11 | A browser abort can leave a submitted database command running. Gate the Console Stop action on the remote cancel service and an active query session ID.                                                               | [Console behavior](../../packages/studio-ui/src/provider.test.tsx)                                                                                         |
| L12 | For a direct-entry Back test, replace the fresh tab's initial document and verify its history length. A Playwright navigation can leave `about:blank` in the stack.                                                     | [Web browser history](../../e2e/web/schema.spec.ts)                                                                                                        |
| L13 | When checkbox groups reuse field paths across tabs, use empty arrays for missing groups. Undefined groups can fall back to the previous tab's defaults.                                                                 | [Explorer panel persistence](../../e2e/web/explorer-panels.spec.ts)                                                                                        |
| L14 | Let React Flow manage hit testing for overlapping handles. Make one handle start and the other end the connection, then use the reported source and target IDs.                                                         | [Schema canvas connections](../../e2e/web/schema-canvas.spec.ts)                                                                                           |
| L15 | A browser can expose the WebGL constructor even when it cannot create a usable context. Check the extensions the layout engine requires, fall back to the CPU, and release the loading overlay on failure.              | [Explorer layout regression](../../e2e/web/explorer-visuals.spec.ts)                                                                                       |
| L16 | MobX shallow collections track membership. Computed label indexes also need the schema revision when type models are edited in place.                                                                                   | [Canvas and table label regression](../../e2e/web/schema-canvas.spec.ts)                                                                                   |
| L17 | Bind fixture results to the identity and target in the actual request. For canvas tests, assert layout geometry and node opacity so a different layout or a missing node fails the test.                                | [GUI](../../e2e/gui/console.spec.ts), [Schema](../../e2e/web/schema-types.spec.ts), [Explorer](../../e2e/web/explorer-visuals.spec.ts)                     |
| L18 | After an active filter changes mode or a query updates an entity, the hidden and dimmed memberships can change at the same count. Observe membership and refresh rules on data changes.                                 | [Explorer filter](../../e2e/web/explorer-visuals.spec.ts)                                                                                                  |
