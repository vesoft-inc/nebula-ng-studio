# Lessons

- **Bind asynchronous work to its scope.** Capture the scope or generation when starting a request. Unmounting a page expires its callbacks, while a successful remote Schema switch still updates the active session. Replacing the session or service invalidates its pending work. [Provider lifecycle](../../packages/studio-ui/src/provider.test.tsx) · [Schema switch](../../packages/studio-ui/src/schema-tree-panel.test.tsx)
- **Rebind resources when their owner changes.** An editor can stay mounted while its Controller changes. Release the handle through the callback that acquired it before binding the new owner. A snapshot change replaces the canvas subtree because its controls capture the workspace. [Editor handoff](../../packages/studio-ui-internal/src/editor/GqlEditor/Editor.test.tsx) · [Snapshot canvas](../../packages/studio-ui-internal/src/explorer/Graph/index.test.tsx)
- **Pass business identifiers through the tree and router.** Read names from node data or semantic selections. Splitting a composite tree key loses hyphens in names, and decoding an already decoded route parameter can change a literal percent escape. Let the router decode each parameter once. [Tree selection](../../packages/studio-ui/src/schema-tree-panel.test.tsx) · [Route parameters](../../apps/web/src/app/paths.test.ts)
- **Observe the data that changes a derived view.** Hidden or dimmed entities can change while their count stays constant. Observe membership and reapply filters when queries or edits change entity properties. Schema label indexes also depend on the revision of models edited in place inside shallow MobX collections. [Explorer filters](../../e2e/web/explorer-visuals.spec.ts) · [Schema labels](../../e2e/web/schema-canvas.spec.ts)
